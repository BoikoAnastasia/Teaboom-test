# Тестовое задание: Карточка товара для Teaboom.ru

Верстка адаптивной карточки товара «Ананасовый улун» с интерактивным переключением фасовки в рамках тестового задания на позицию Frontend-верстальщика.

## Демо

- **Ссылка на GitHub Pages:** https://boikoanastasia.github.io/Teaboom-test/

## Технологический стек

- **HTML5:** Семантическая разметка (`<header>`, `<main>`, `<section>`, `<ul>`, `<footer>`).
- **CSS3 / SCSS:** Использование методологии БЭМ, препроцессора SCSS, CSS-переменных, Flexbox.
- **JavaScript (Vanilla JS):** Чистый код без сторонних фреймворков и библиотек.

## Реализованный функционал

1. **Интерактивная фасовка:** Динамическое обновление актуальной цены, старой цены и артикула товара при клике на разные варианты веса (100г, 500г, 1000г, 5000г).
2. **Адаптивность:** Полная адаптивная верстка под ключевые разрешения, указанные в ТЗ (Desktop 1440px, Tablet 768px, Mobile 375px), а также корректное отображение на промежуточных экранах.
3. **Эффекты взаимодействия:** Оформлены состояния `:hover` и `:active` для кнопок, карточек и интерактивных элементов.
4. **Прижатый футер:** Реализована структура Flexbox-колонки, удерживающая футер у нижней границы экрана при любом количестве контента.

## Инструкция по запуску

Проект не требует сложной сборки или установки дополнительных node-модулей, его можно запустить локально.

### Вариант 1 (Самый простой)

1. Скачайте архив или клонируйте репозиторий:
   ```bash
   git clone https://github.com/BoikoAnastasia/Teaboom-test.git
   ```
2. Откройте файл `index.html` в любом современном браузере двойным щелчком мыши.

### Вариант 2 (Для разработки с Live Reload)

Если вы используете **Visual Studio Code**:

1. Установите расширение **Live Server**.
2. Нажмите правой кнопкой мыши по `index.html` и выберите **«Open with Live Server»**.

_Примечание: Если вам потребуется перекомпилировать стили, в проекте использовался плагин **Live Sass Compiler** для VS Code._
